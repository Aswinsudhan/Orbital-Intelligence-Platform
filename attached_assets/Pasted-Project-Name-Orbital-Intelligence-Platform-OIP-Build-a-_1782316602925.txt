Project Name: Orbital Intelligence Platform (OIP)

Build a production-ready full-stack web application called "Orbital Intelligence Platform" focused on real satellite tracking, orbital analytics, collision risk analysis, orbital congestion forecasting, and satellite risk scoring.

IMPORTANT:
Do NOT use mock satellite data for the core application.
Use real publicly available satellite orbital data from CelesTrak as the  source. And also from from live datasets.

Technology Stack:

* Frontend: React
* Backend: Python Flask
* Database: PostgreSQL (fallback SQLite)
* Data Processing: Python
* Charts: Plotly or Chart.js
* Modern responsive UI
* Dark space-themed design
